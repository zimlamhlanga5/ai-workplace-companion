# AI Workplace Productivity Assistant

## Project Overview

AI Workplace Productivity Assistant is a modern web application designed to help professionals automate everyday workplace tasks using Artificial Intelligence. The platform combines multiple AI-powered productivity tools into a single dashboard to improve efficiency, communication, planning, and research.

## Features

* Smart Email Generator
* Meeting Notes Summarizer
* AI Task Planner
* AI Research Assistant
* AI Workplace Chatbot
* Responsive Dashboard Interface
* Editable AI Outputs
* Responsible AI Disclaimer

## Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* OpenAI API
* Lovable AI
* GitHub

## Installation

1. Clone the repository.
2. Install dependencies:
   npm install
3. Start the application:
   npm run dev

## Responsible AI

This application provides AI-generated content that may contain inaccuracies. Users should review and verify outputs before making business decisions.
